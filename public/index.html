Pulse help center

Quick answers for setting up monitors, understanding incidents, and troubleshooting checks.

Monitor setup

What URL can I monitor?

Use a public HTTPS endpoint. Pulse blocks private, local, link-local, and reserved network addresses for safety.

When does an incident open?

The first failed check marks the monitor degraded. A second consecutive failure opens an incident. The next passing check resolves it.

What do assertions do?

They verify response text or JSON fields after the status and timeout checks pass.

Troubleshooting

A check is not running

Confirm the monitor is active, the URL uses HTTPS, and the endpoint is publicly reachable.

Why is a monitor “Not checked”?

New monitors wait for their first scheduled run. Use Run now if you want an immediate result.

Need to inspect a failure?

Open Check runs for the status, latency, and exact failure reason, then open the monitor for its timeline.
